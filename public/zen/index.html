Nothing but
a cursor.

zen is a text editor for the terminal. No status bar, no line numbers, no menus, no shortcuts. You write. When you want to save, you type ;w.


    

    
  

  
Click and write. Type quickly: ;# count   ;k delete line   ;y duplicate   ;u undo   ;;date


  

    
Commands are typed, not pressed.

    
There is no Ctrl and no Alt. A command is a short run of ordinary keys typed quickly. The keys show up as text, and the moment the sequence completes they vanish and the command runs.

    
Type the same keys slowly and they stay as text. Every sequence can be changed to anything you like, a symbol pair or a whole word.

    

      
;wsave

      
;qquit

      
;xsave and quit

      
;u ;rundo, redo

      
;ffind

      
;hfind and replace

      
;ggo to line

      
;vselect

      
;c ;d ;pcopy, cut, paste

      
;kdelete line

      
;jre-wrap paragraph

      
;#word count

      
;ttypewriter scrolling

      
;ofocus dimming

    

  


  

    
Small on purpose.

    

      

        
An empty screen

        
The bottom row appears only when zen has to ask you something, and is gone on the next key.

      

      

        
One binary

        
1.6 MB, statically linked. Written in Rust with no dependencies at all.

      

      

        
One config file

        
Margins, cursor, colours, every sequence and every feature. Plain text, read at startup.

      

      

        
Made for prose

        
Soft wrap, typewriter scrolling, focus dimming, paragraph reflow, text expansions.

      

      

        
Careful with your words

        
Atomic saves, crash recovery, a warning if the file changed on disk. It reopens where you left off.

      

      

        
At home in a shell

        
Pipe text in. Bind a sequence to any command and run it over your selection.

      

    

  


  

    
Install.

    
Linux, with Rust 1.82 or newer and make.

    

      

$ git clone https://github.com/vajradevam/zen.git
$ cd zen
$ make
$ sudo make install

    

    
Then zen notes.txt. Everything else is in man zen and the readme.
